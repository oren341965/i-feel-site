## האתר והטכנולוגיה

- דומיין: `i-feel.co.il`. אתר **Astro סטטי** (Astro + Tailwind), CSS מקומפל תחת `/_astro/`.
- אירוח: JetServer (cPanel). פריסה דרך GitHub Actions → runner במשרד → FTPS. אין FTP/cPanel ידני.
- `public/sitemap.xml` **ידני** — כל דף חדש חייב להתווסף אליו באותה עבודה.
- קבצים רגישים: `public/api/lead.php`, `public/.htaccess`, קובצי אימות GSC — לא נוגעים בלי כוונה מפורשת.
- `public/api/config.php` — מקומי לשרת, **אינו** ב-Git, לא נפרס.
- מבנה עמודים: `src/pages/**.astro`; פרויקטי BMS תחת `src/pages/structure-control/`;
  תמונות תחת `public/projects/<slug>/` ו-`public/assets/structure-projects/img/`.
