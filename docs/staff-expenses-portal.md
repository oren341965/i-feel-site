# אזור עובדי I Feel לדיווח הוצאות

## כתובת

`https://i-feel.co.il/staff-expenses/`

העמוד אינו מקושר מתפריטי האתר ואינו נוסף ל-sitemap.

## מה כלול

- כניסה עם שם משתמש וסיסמה.
- תפקיד עובד: מילוי דיווחים בלבד.
- תפקיד מנהל: צפייה בכל הדיווחים, הורדת מסמכים, שינוי סטטוס, ייצוא CSV וניהול משתמשים.
- דיווח רכב ונסיעות בארץ: דלק, טיפול, תיקון, חניה, אגרות, ביטוח, רישוי, שטיפה, השכרה, מוניות ותחבורה.
- דיווח נסיעה לחו״ל: נוסע, תפקיד, מטרה, יעד, תאריכים, ימי עבודה, PNR ופירוט שורות עבור טיסות, מלון, אוכל, רכב שכור, תחבורה, חניה, תקשורת, ביטוח/אשרה, כנס והוצאות אחרות.
- דיווח הוצאה כללית.
- העלאת עד 20 מסמכים בדיווח, עד 12MB לקובץ ועד 60MB בסך הכול.

## אבטחה

- כל תוכן ודף הורדה דורשים session מאומת.
- קבצים נשמרים כברירת מחדל ב-`/home/ifeelco/private_expenses`, מחוץ ל-`public_html`.
- הקבצים מקבלים שמות אקראיים ומוגשים רק כ-attachment לאחר בדיקת הרשאת מנהל.
- סיסמאות נשמרות כ-hash בלבד.
- הגבלת ניסיונות כניסה ל-5 ניסיונות בכל 15 דקות לכתובת IP.
- CSRF, cookies מסוג HttpOnly ו-SameSite, מניעת cache, noindex, CSP, חסימת iframe ובדיקת MIME לקבצים.
- יומן ביקורת שומר פעולות מרכזיות ו-hash של כתובת IP, לא את ה-IP הגולמי.

## אחסון ותחזוקה

הפורטל טוען את `public_html/api/config.php` הקיים, אם נמצא. אפשר להגדיר בו:

```php
define('EXPENSE_PORTAL_STORAGE_PATH', '/home/ifeelco/private_expenses');
```

אפשר גם להגדיר משתמשים בשרת באמצעות `EXPENSE_PORTAL_USERS`, אך לאחר הכניסה הראשונה ניתן לנהל משתמשים מתוך המסך של אורן. מומלץ ליצור חשבון אישי לכל עובד, להחליף את הסיסמאות הזמניות ולהשבית את החשבון המשותף `employee` לאחר מכן.

יש לכלול את תיקיית `private_expenses` בגיבוי האחסון של JetServer.

## פריסה

אין דיפלוי אוטומטי. לאחר `git pull` במחשב המשרד:

1. להריץ `npm run build`.
2. להעלות את כל התוכן של `dist/staff-expenses/` אל `public_html/staff-expenses/`.
3. להעלות את `dist/robots.txt` משום שנוספה חסימה לנתיב.
4. לוודא שהכניסה עובדת, שהעלאה יוצרת תיקייה מחוץ ל-`public_html`, ושקובץ ניתן להורדה רק מחשבון מנהל.
5. לעדכן את תג `live` לפי נוהל הפריסה הקיים.
