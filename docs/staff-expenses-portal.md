# אזור עובדי I Feel לדיווח הוצאות

## כתובת

`https://i-feel.co.il/staff-expenses/`

העמוד אינו מקושר מתפריטי האתר ואינו נוסף ל-sitemap.

## כניסה והרשאות

- מסך הכניסה מבקש כתובת דוא״ל ארגונית בלבד.
- מתקבלות רק כתובות שמסתיימות בדיוק ב-`@i-feel.co.il`.
- לאחר הזנת הכתובת נשלח אליה קוד חד-פעמי בן 6 ספרות. הזנת כתובת בלבד אינה פותחת את הדוח.
- הקוד תקף ל-10 דקות ולשימוש אחד בלבד, עם הגבלה של 5 ניסיונות אימות.
- בקשת קוד מוגבלת גם בין sessions: עד 5 בקשות בכל 15 דקות לכל שילוב של כתובת IP וכתובת דוא״ל, ובהפרש של 60 שניות לפחות.
- כל כתובת חברה מאומתת מקבלת הרשאת עובד למילוי דיווחים בלבד.
- `oren@i-feel.co.il` מקבלת כברירת מחדל הרשאת מנהל לצפייה בכל הדיווחים, הורדת מסמכים, שינוי סטטוס וייצוא CSV.

## מה כלול

- מסירת מערכת בית חכם לדייר: חיפוש ייעודי לפי שם פרויקט, שם דייר או שניהם, ובחירת פרויקט ודירה מ-Monday בזמן אמת פותחים מיד את מלוא טופס הטכנאי. הטופס מפיק פרטי כניסה, מחייב את הצילומים הנדרשים, ושומר ושולח סיכום פנימי ומייל לדייר. קישור הענן נשלף בצד השרת מגיליון הפרויקט ב-Google Drive לפי דוא״ל/טלפון ובניין-דירה, ואינו מוקלד בידי הטכנאי. קבוצות Monday בעלות אותו שם מוצגות כפרויקט אחד, והדיירים מכל הקבוצות המאוחדות נשמרים ברשימה. מונחי החיפוש נשמרים לזמן קצר ב-session ואינם נכתבים ב-URL או באינדקס האתר.
- דיווח רכב ונסיעות בארץ: דלק, טיפול, תיקון, חניה, אגרות, ביטוח, רישוי, שטיפה, השכרה, מוניות ותחבורה.
- דיווח נסיעה לחו״ל: נוסע, תפקיד, מטרה, יעד, תאריכים, ימי עבודה, PNR ופירוט שורות עבור טיסות, מלון, אוכל, רכב שכור, תחבורה, חניה, תקשורת, ביטוח/אשרה, כנס והוצאות אחרות.
- דיווח הוצאה כללית.
- העלאת עד 20 מסמכים בדיווח, עד 12MB לקובץ ועד 60MB בסך הכול.

## אבטחה

- כל תוכן ודף הורדה דורשים session מאומת לאחר אימות קוד שנשלח לתיבת דוא״ל של החברה.
- קבצים נשמרים כברירת מחדל ב-`/home/ifeelco/private_expenses`, מחוץ ל-`public_html`.
- הקבצים מקבלים שמות אקראיים ומוגשים רק כ-attachment לאחר בדיקת הרשאת מנהל.
- הגבלת ניסיונות כניסה ל-5 ניסיונות בכל 15 דקות לכתובת IP.
- CSRF, cookies מסוג HttpOnly ו-SameSite, מניעת cache, noindex, CSP, חסימת iframe ובדיקת MIME לקבצים.
- Cookie הכניסה מסומן `Secure` בשרת גם כאשר LiteSpeed מסיים TLS לפני PHP. הפורטל אינו מבצע redirect פנימי נוסף ל-HTTPS; כלל האתר הראשי הוא מקור האמת כדי למנוע redirect loop.
- לפני הצגת מסך הכניסה נבדקים PHP 7.4 ומעלה (גרסת הייצור ב-JetServer), session פעיל, `fileinfo`, מגבלות ההעלאה, transport לדוא״ל וכתיבה/קריאה/מחיקה של קובץ בדיקה בתיקייה הפרטית. כשל מחזיר עמוד תחזוקה ו-HTTP 503 ללא חשיפת פרטי שרת.
- יומן ביקורת שומר פעולות מרכזיות ו-hash של כתובת הדוא״ל וכתובת ה-IP, לא את הערכים הגולמיים.
- רשימת הדיירים אינה מוטמעת בקוד או ב-JavaScript. מזהי קבוצה ופריט בלבד עוברים בכתובת/בטופס, והשרת מאמת מחדש את הדייר מול Monday לפני כל שמירה.
- מזהי גיליונות Google Drive וקובץ ההרשאות נשמרים רק ב-`config.php` ובקובץ פרטי מחוץ ל-`public_html`. הדפדפן אינו מקבל את מזהה הגיליון, את הרשימה המלאה או הרשאת Google; במסירה הוא מקבל רק חיווי אם נמצא קישור, והשרת שולף אותו מחדש לפני השמירה.
- צילומי מסירה נשמרים תחת `tenant-handovers` באותה תיקייה פרטית; קישורי התמונות דורשים session מאומת באזור העובדים.

## הגדרות שרת אופציונליות

הפורטל טוען את `public_html/api/config.php` הקיים, אם נמצא. אפשר להגדיר בו:

```php
define('EXPENSE_PORTAL_STORAGE_PATH', '/home/ifeelco/private_expenses');
define('EXPENSE_PORTAL_EMAIL_DOMAIN', 'i-feel.co.il');
define('EXPENSE_PORTAL_FROM_EMAIL', 'no-reply@i-feel.co.il');
define('EXPENSE_PORTAL_ADMIN_EMAILS', [
    'oren@i-feel.co.il',
]);

define('TENANT_HANDOVER_MONDAY_TOKEN', 'SERVER_ONLY_MONDAY_TOKEN');
define('TENANT_HANDOVER_MONDAY_BOARD_ID', '18399467324');
define('TENANT_HANDOVER_MONDAY_SALES_BOARD_ID', '2732725332');
define('TENANT_HANDOVER_MONDAY_API_VERSION', '2026-07');
define('TENANT_HANDOVER_INTERNAL_RECIPIENTS', 'sagiv@i-feel.co.il,support@i-feel.co.il');

define('TENANT_HANDOVER_GOOGLE_SERVICE_ACCOUNT_FILE', '/home/ifeelco/private_expenses/google-drive-reader.json');
define('TENANT_HANDOVER_GOOGLE_DRIVE_FOLDER_ID', 'OPTIONAL_SHARED_FOLDER_ID');
define('TENANT_HANDOVER_CLOUD_SHEETS', [
    // מפתח מומלץ: מזהה קבוצת הפרויקט ב-Monday. הערכים נשארים רק בשרת.
    'group_example' => [
        'spreadsheet_id' => 'GOOGLE_SPREADSHEET_ID',
        'sheet' => 'גיליון1',
        'range' => 'A1:AZ2000',
    ],
]);
```

לטוקן Monday נדרשת הרשאת `boards:read` ללוח `מחלקת פרויקטים - דיירים` וללוח המכירות המקושר. אפשר להשתמש ב-`MONDAY_API_TOKEN` הקיים במקום הקבוע הייעודי, אך אין לשמור אף טוקן ב-Git. רשימת הפרויקטים ושמות הדיירים נשלפים רק מהלוח הייעודי. טלפון ודוא״ל נקראים מהעמודות הישירות `phone2` ו-`email`; מספר דירה, בניין וכתובת נקראים מפריט המכירות המקושר דרך `connect_boards`. קבוצות תפעוליות כמו `דיירים - בהתקנה` אינן מוצגות כפרויקטים, ואין סינון לפי סטטוס מכירה.

לחיבור Google Drive יש ליצור service account לקריאה בלבד, לשמור את קובץ ה-JSON שלו מחוץ ל-`public_html`, ולשתף איתו לצפייה בלבד את תיקיית גיליונות הפרויקטים או את הגיליונות הרלוונטיים. אם שם גיליון Google Sheets זהה לשם הפרויקט ב-Monday, המערכת יכולה לאתר אותו אוטומטית בתיקייה המוגדרת. כאשר השמות שונים, מגדירים מיפוי מפורש ב-`TENANT_HANDOVER_CLOUD_SHEETS`. הגיליון צריך לכלול שורת כותרות עם `שם רוכש`/`שם דייר`, `דירה`, `טלפון נייד` או `כתובת דוא״ל`, ו-`לינק`/`לינק HA`. התאמה שאינה חד-משמעית נחסמת ואינה שולחת קישור.

יש לוודא שפונקציית `mail()` של PHP פעילה ב-JetServer ושדואר מהכתובת `no-reply@i-feel.co.il` מורשה להישלח. יש לכלול את תיקיית `private_expenses` בגיבוי האחסון.

אם `mail()` אינו מספק מסירה אמינה, אפשר לבחור SMTP מאומת. הערכים הבאים הם דוגמה בלבד; שם המשתמש והסיסמה נשמרים רק ב-`public_html/api/config.php` שבשרת ואינם נכנסים ל-Git:

```php
define('EXPENSE_PORTAL_MAIL_TRANSPORT', 'smtp');
define('EXPENSE_PORTAL_SMTP', [
    'host' => 'smtp.example.com',
    'port' => 587,
    'encryption' => 'starttls', // או tls עם פורט 465
    'username' => 'no-reply@i-feel.co.il',
    'password' => 'SERVER_ONLY_SECRET',
    'timeout' => 10,
]);
```

## פריסה

הפריסה עוברת רק במסלול המשותף ובשני שלבים. בשלב הראשון הפורטל נבדק בכתובת הישירה, ללא קישור “כניסת עובדים” באתר:

1. work branch ו-Draft PR דרך `scripts/workstations/publish-work.ps1`.
2. check ירוק בשם `Validate site`.
3. merge מאושר ל-`main`.
4. GitHub Actions מעביר את `dist` המאומת ל-runner של מחשב המשרד.
5. `Deploy production` מעלה ב-FTPS ללא מחיקות ומריץ verify-live.
6. בכתובת הישירה מוודאים שאין 500 או redirect loop, מזינים כתובת `@i-feel.co.il`, מוודאים שקוד מתקבל ושכתובת חיצונית נדחית.
7. במסך “מסירות דיירים” מוודאים שפרויקט ודירה נטענים מ-Monday, ששני צילומי החובה נשמרים מחוץ ל-`public_html`, ושמייל פנימי ומייל דייר נשלחים בלי לחשוף PII למשתמש שאינו מחובר.
8. מוודאים ששני סוגי דיווח עם מסמכים נשמרים מחוץ ל-`public_html`, שהורדה ו-CSV דורשים מנהל וששינוי סטטוס נשמר.
9. רק לאחר שכל בדיקות הקבלה עברו פותחים PR נפרד להחזרת קישור “כניסת עובדים” ל-Header ולעדכון תג `live`.
