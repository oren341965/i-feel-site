## חסר — תמיכה טכנית (עדיפות ראשונה)

מבוסס על "תקלות נפוצות" ו-"אני רוצה ל…" במרכז השירות `/help/`. כל אלה מדריכי how-to קצרים
(רצוי אנכי 9:16) שנכנסים לקטגוריית **הדרכות שימוש** ב-/video/, ולרוב גם לדף-נושא ייעודי.

> הערה: "לחבר את האפליקציה" כבר מכוסה (קיים ביוטיוב/באתר) — לא ברשימת החוסרים.

- [ ] **מתג לא מגיב** — מה לבדוק ומתי לפתוח קריאה.
- [ ] **תאורה לא נדלקת / לא נכבית**
- [ ] **אחרי הפסקת חשמל** — מה לעשות כשהמערכת חוזרת.
- [ ] **אינטרקום / וידאו** — מענה ופתיחת דלת מהאפליקציה.
- [ ] **להוסיף תרחיש / סצנה** — יצירת אוטומציה באפליקציה.
- [ ] **תריסים ווילונות** — שליטה והגדרת מצבים.

## חסר — פרויקטים ו-BMS (מסומן כ-placeholder ב-/video/)

- [ ] **קולנוע ביתי** — כרטיס placeholder פעיל בקטגוריית "חדרי ישיבות ואודיו".
- [ ] **סיורי פרויקטים** — וילות, בנייני יוקרה, בתי מלון (קטגוריית "סרטוני פרויקטים", כרגע placeholder).
- [ ] **BMS נוספים** — סיורי בקרת מבנה נוספים מעבר לסרטון המסחרי הקיים.

## חסר — הסברי מוצר ותכנון

- [ ] **קופסאות השקעה לקו אפס למסכי Siemens TC4/TC5** — מק״טים `TAV TC4` ו-`TAV TC5`; הטמעה ב-`/knx-switch-advisor/#flush-boxes` לאחר קבלת YouTube ID ותאריך העלאה.
