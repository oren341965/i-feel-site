## ⚠️ לקח חשוב לפעם הבאה

בסבב הזה נוצר במחשב המשרד קומיט מקומי (`c13d060`) שמחק את דף הדסה לגמרי (דף + sitemap + llms + כרטיס בדף הבית + 301 ב-.htaccess). הענף שם **סטה מ-origin/main ולא הכיל את `525e2c8`** — דחיפה משם הייתה מוחקת את הדף וגם דורסת את תיקון הניסוח. הקומיט נזרק (`git reset --hard origin/main`) אחרי אישור מפורש של אורן.

**כללים שנגזרים מזה:**
1. **תמיד `git pull origin main` לפני שמתחילים לערוך** — בשני המחשבים.
2. **לדחוף לפני שפורסים.** אם קומיט לא ב-GitHub, הוא לא קיים.
3. **לפני `push` — לבדוק סטייה:** `git log --oneline origin/main..HEAD` ו-`HEAD..origin/main`.
4. **מחיקת דף / שינוי `.htaccess` = אישור מפורש של אורן**, לא פרשנות של סשן.
5. אחרי דיפלוי: `git tag -f live HEAD` + `git push origin live --force` — כדי ששני המחשבים יחלקו נקודת ייחוס.
