# סרטוני מפסקי KNX — פורסמו

בעל המשימה: אורן. אין למזג את הטיוטה עד להשלמת העלאת YouTube, הכנסת המזהה והתאריך האמיתיים ובדיקת ההטמעות.

- YouTube ואתר: `knx-switches-horizontal.mp4`, ‏1920×1080, שמע, 104.600 שניות.
  מקור: https://drive.google.com/file/d/1GmnmZVuxlMP8GocsYYc2DN7iXtFpifzT/view
- TikTok: `knx-switches-vertical.mp4`, ‏1080×1920, שמע, 104.606 שניות.
  מקור: https://drive.google.com/file/d/1biZ14b7rhbJ7o_s9QGLr79vKuR-eUWIK/view
- הסרטון האופקי כבר ממותג בלוגו I Feel בפתיחה ובסיום. אין להוסיף מיתוג כפול.
- מטא־דאטה וכיתוב מוכנים בקבצים הסמוכים בהתאם להנחיות אורן.

## השלמה

1. להגדיר את חיבור OAuth הקיים לפי `docs/youtube-api-uploader.md`, ולאמת `@ifeelsmarthome` באמצעות `npm run youtube:verify`.
2. להעלות את האופקי עם `youtube-metadata.json` בכלי המוגן, עם אישורי ההעלאה והפרסום שאורן נתן.
3. לעדכן `src/data/knx-switches-video.json`: מזהה YouTube אמיתי ותאריך העלאה אמיתי. ללא שניהם, הסרטון והסכמה אינם מופיעים באתר.
4. ההטמעה מוכנה בעמוד יועץ מפסקי KNX לפני מדריך המוצרים, ובקטגוריית הסברים על בית חכם ו־KNX ב־`/video/`. סכמת VideoObject בשני העמודים משתמשת באותו מקור מידע.
5. לסמן ב־`docs/video-plan.md` רק לאחר ההעלאה ולהריץ build ובדיקת שתי ההטמעות.
6. TikTok: הסרטון הועלה ל־`@orenlevy4` עם הכותרת וההאשטגים המאושרים. בדיקת TikTok הסתיימה, והפוסט מופיע עם פרטיות ״כולם״. קישור: https://www.tiktok.com/@orenlevy4/video/7695105890424196359

YouTube פורסם דרך YouTube Studio בערוץ המאומת `@ifeelsmarthome` ב־2026-10-10 עם המטא־דאטה המאושרים. קישור: https://youtu.be/puG0qeaD-oU . בדיקת YouTube הסתיימה ללא בעיות. המזהה ותאריך ההעלאה הוזנו במקור המידע המשותף לשתי ההטמעות.
