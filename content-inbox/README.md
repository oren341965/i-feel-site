# 📥 תיקיית קליטת תכנים — content-inbox

**התיקייה הזו מיועדת לקרן (שיווק דיגיטלי).**

לכאן מעלים תכנים חדשים לאתר: טקסטים של מאמרים, תמונות, קטלוגים וכל חומר שיווקי אחר.
התיקייה הזו **לא משפיעה על האתר החי** — שום דבר כאן לא מתפרסם אוטומטית.
אחרי שהתוכן מאושר, אורן (או קלוד) משלבים אותו בדפי האתר, בונים את האתר ומעלים לשרת.

## איך מעלים תוכן חדש — 4 שלבים

1. נכנסים לתיקייה הזו בגיטהאב ולוחצים **Add file ← Upload files**
2. גוררים את הקבצים (Word / טקסט / תמונות)
3. למטה בוחרים **Create a new branch for this commit and start a pull request** — ⚠️ לעולם לא בוחרים "Commit directly to the main branch"
4. לוחצים **Propose changes** ואז **Create pull request**

זהו! אורן מקבל התראה, מאשר, והתוכן משולב באתר.

## כללי שמות קבצים

- שמות באנגלית בלבד, אותיות קטנות, מקפים במקום רווחים
  - ✅ `smart-home-tips-july-2026.docx`
  - ❌ `טיפים לבית חכם.docx`
- לכל נושא — תיקיית משנה משלו, למשל: `content-inbox/2026-07-smart-home-tips/`
- תמונות: JPG או PNG, עד 500KB לתמונה אם אפשר

## מה אסור

- ❌ לא מוחקים ולא משנים קבצים קיימים — רק מוסיפים חדשים
- ❌ לא נוגעים בתיקיות `src`, `public`, `dist` או בקבצים בשורש הפרויקט
- ❌ לא בוחרים אף פעם "Commit directly to the main branch"

המערכת מוגנת: גם אם טועים, שום שינוי לא נכנס לאתר בלי אישור של אורן.
