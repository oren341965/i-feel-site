# Professional social-relations ownership

This contract governs `maya-instagram-relations` across Instagram and Facebook. `ai-marketing-manager` owns the relationship objective, backlog, watchlist policy, wording policy, monthly quality review and skill lifecycle. `ai-sales-manager` remains the source of the reconciled Monday candidate roster, project-state evidence and sales-capacity context. Do not create another manager, Maya worker or outreach queue.

## Ownership map

| Responsibility | Owner | Boundary |
| --- | --- | --- |
| Program idea, backlog, voice and contact policy | `ai-marketing-manager` | May propose improvements; cannot authorize its own external action. |
| Monday candidate roster and project evidence | `ai-sales-manager` | Reads and reconciles the approved Monday boards; does not choose social profiles or approve outreach. |
| Watchlist governance and monthly quality review | `ai-marketing-manager` | Uses strong identity evidence, keeps versions bounded and changes canonical policy only through a repository work branch and Pull Request. |
| Profile resolution, public-content evidence and drafts | Maya through `maya-instagram-relations` | Uses verified I Feel sessions and the approved roster/watchlist; does not set strategy, expand scope or approve its own outreach. |
| External send | Maya after exact approval | Requires the verified handle, chosen platform, source item and final wording. |
| Business exceptions and final authority | Oren | Approves protected actions, new outreach scope, merge, installation and scheduler activation. |

## Monthly cycle

1. `ai-sales-manager` supplies a complete reconciled candidate roster and verified project states. A name alone never proves profession, profile identity or project relationship.
2. `ai-marketing-manager` versions the approved watchlist, relationship objective and bounded tone guidance without expanding the roster silently.
3. Maya resolves eligible public professional profiles and returns source evidence, exclusions and exact proposed wording under `maya-instagram-relations`.
4. `ai-marketing-manager` checks specificity, sincerity, cadence, cross-channel duplicates, opt-outs and unanswered-attempt limits. No-message is a valid outcome.
5. Oren approves or rejects the exact outbound batch and chosen single platform. Maya sends only the approved text and verifies the intended thread; the same reason is never messaged on both platforms.
6. The manager reviews bounded aggregates such as profiles reviewed, meaningful updates, replies, relationship-progressing responses, cooldowns and opt-outs. Never optimize for message volume.

## Evidence and privacy

The exact approval batch stays in the authorized review surface. Management telemetry may contain only counts, program version, run state and bounded blocker codes. Never place Monday rows, private messages, captions, handles, profile URLs, project names or personal details in ordinary logs, Git or aggregate telemetry.
