# Professional social-relations ownership

This contract governs `maya-instagram-relations` across Instagram and Facebook. `ai-marketing-manager` owns the relationship objective, backlog, watchlist policy, wording policy, monthly quality review and skill lifecycle. `ai-sales-manager` remains the source of the reconciled Monday candidate roster, project-state evidence and sales-capacity context.

## Ownership map

| Responsibility | Owner | Boundary |
| --- | --- | --- |
| Program idea, backlog, voice and contact policy | `ai-marketing-manager` | May propose improvements; cannot authorize its own external action. |
| Monday candidate roster and project evidence | `ai-sales-manager` | Reads and reconciles approved boards; does not choose profiles or approve outreach. |
| Profile resolution, public evidence and drafts | Maya through `maya-instagram-relations` | Uses verified sessions and the approved roster; does not set strategy or approve its own outreach. |
| External send | Maya after exact approval | Requires verified handle, platform, source item and final wording. |
| Final authority | Oren | Approves protected actions, new scope, merge, installation and scheduler activation. |

## Monthly cycle

1. `ai-sales-manager` supplies a complete candidate roster and verified project states.
2. `ai-marketing-manager` versions the approved watchlist, objective and tone guidance.
3. Maya resolves eligible public profiles and returns evidence, exclusions and proposed wording.
4. The manager checks specificity, cadence, duplicates, opt-outs and unanswered-attempt limits.
5. Oren approves or rejects the exact outbound batch and single chosen platform.
6. The manager reviews bounded aggregates; never optimize for message volume.

Management telemetry may contain only counts, program version, run state and bounded blocker codes. Never place Monday rows, private messages, captions, handles, profile URLs, project names or personal details in ordinary logs, Git or aggregate telemetry.
