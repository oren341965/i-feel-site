# הוספה לגלריות i-feel.co.il

## שלוש גלריות, שלושה מנגנונים שונים

הריפו: `C:\Users\USER\i-feel-site`. **חשוב**: שתיים מהגלריות הן HTML סטטי ב-`public/`
(עוקפות את Astro — נכנסות ל-dist כמו-שהן), ואחת עוברת דרך צינור ה-Astro הרגיל.

| גלריה | URL חי | קובץ לעריכה | תמונות ב- | מנגנון |
|-------|--------|-------------|-----------|--------|
| **BMS / בקרת מבנה** | `/structure-control/projects/` | `public/structure-control/projects/index.html` | `public/assets/structure-projects/img/` | מערך JS `const P = [...]` + רשימת זחלנים סטטית |
| **בתים פרטיים** | `/projects/private-homes/` | `public/projects/private-homes/index.html` | `public/assets/private-homes-gallery/` | גריד `<img>` רגיל ב-HTML |
| **יזמים / בנייה רוויה** | `/contractor-customer-care/projects/` | `src/page-html/contractor-projects.html` | `public/assets/projects/` | גריד `<img>` דרך Astro |

לפני כל עבודה — פתח את קובץ הגלריה הרלוונטי וקרא את המבנה הקיים. חקה אותו בדיוק.

## שלב 1 — קליטת התמונות

1. קבל מאורן: התמונות (תיקייה / PDF / צילומי WhatsApp), לאיזו גלריה, ופרטי הפרויקט
   (שם, מיקום, מה נעשה שם, אילו מערכות — KNX / DALI / Siemens Desigo וכו').
2. **זכויות**: תמונות שאורן מספק מהפרויקטים/קטלוגים שלו — מאושרות (הוא אישר שהכול נרכש
   או צולם על ידם). תמונה ממקור לא ברור — שאל לפני שמעלים.
3. **כפילויות**: בדוק שהתמונה/הפרויקט לא כבר בגלריה (השווה שמות פרויקטים ותוכן, לא רק
   שמות קבצים).

## שלב 2 — אופטימיזציה ושמות

- יעד: JPG (או PNG לצילומי מסך/שרטוטים), רוחב עד ~1600px, עד ~500KB לקובץ.
- אם `magick` (ImageMagick) לא מותקן, השתמש ב-.NET דרך PowerShell:

```powershell
Add-Type -AssemblyName System.Drawing
$img = [System.Drawing.Image]::FromFile($in)
$w = [Math]::Min(1600, $img.Width); $h = [int]($img.Height * ($w / $img.Width))
$bmp = New-Object System.Drawing.Bitmap($img, $w, $h)
$enc = [System.Drawing.Imaging.ImageCodecInfo]::GetImageEncoders() | Where-Object { $_.MimeType -eq 'image/jpeg' }
$p = New-Object System.Drawing.Imaging.EncoderParameters(1)
$p.Param[0] = New-Object System.Drawing.Imaging.EncoderParameter([System.Drawing.Imaging.Encoder]::Quality, 82L)
$bmp.Save($out, $enc, $p); $bmp.Dispose(); $img.Dispose()
```

- שמות קבצים: אנגלית, kebab-case, תיאוריים — `villa-savyon-lighting.jpg`, לא `IMG_4821.jpg`.
  חריג: בגלריית ה-BMS הקבצים הקיימים נקראים `imageN.png` / `cat-*.jpg` — שמור על הסגנון הקיים שם.
- העתק לתיקיית ה-assets של הגלריה הנכונה (ראה טבלה).

## שלב 3 — הוספה לגלריה

### גלריית BMS (המורכבת מבין השלוש)

הקובץ מכיל **שלושה** דברים שחייבים להישאר מסונכרנים:

1. **מערך `const P = [...]`** — כל פרויקט הוא אובייקט עם השדות:
   `n` (מספר רץ), `t` (שם), `loc` (מיקום), `cat` (קטגוריה מתוך `const CATS`), `tech` (למשל `'KNX · DALI'`),
   `img` (שם קובץ מ-`/assets/structure-projects/img/`), `ch` (האתגר), `sol` (הפתרון), `sys` (המערכות),
   `scope[]` (היקף), `ben[]` (תועלות). כתוב עברית מקצועית באותו סגנון כמו הרשומות הקיימות.
2. **רשימת הזחלנים הסטטית** בתוך `<div class="grid" id="grid">` — כרטיס `<article class="card">`
   לכל פרויקט (JS מחליף אותה בטעינה, אבל גוגל וה-AI קוראים אותה!). פרויקט חדש במערך `P`
   בלי כרטיס סטטי = בלתי נראה ל-SEO. שמור על שם זהה בשני המקומות.
3. **`const PROJECT_URLS`** — אם לפרויקט יש דף מקרה-בוחן (תחת `/structure-control/...`), הוסף מיפוי.

בנוסף: דף `/projects/` (`src/page-html/page-13.html`) מכיל callout עם **מספר פרויקטי ה-BMS**.
הוספת פרויקטים = לעדכן את המספר שם, וכן כל מקום אחר שמצטט את המספר (למשל llms.txt).
מספרים מפורסמים חייבים להישאר אמת.

### גלריית בתים פרטיים / גלריית יזמים

גריד `<img>` פשוט — העתק בלוק קיים והתאם:
- `src` לנתיב התמונה החדש, `loading="lazy"`.
- `alt` בעברית, תיאורי ואמיתי: `"מערכת KNX בווילה בסביון — לוח בקרה"`, לא `"תמונה 1"`.
- כיתוב (אם יש בגריד הקיים) — באותו פורמט.

## שלב 4 — Build ואימות

```powershell
cd C:\Users\USER\i-feel-site
npm run build
```

- ודא שהתמונות החדשות הגיעו ל-`dist\assets\...` ושדף הגלריה ב-`dist\` מכיל את הרשומות החדשות.
- בגלריית BMS: ודא שה-JS עדיין תקין — ספירת פתיחה/סגירה של סוגריים במערך `P` (פסיק חסר
  שובר את כל הגלריה). אם אפשר, הרם preview ובדוק שהגריד נטען והפילטרים עובדים.
- בדוק שגודל כל תמונה סביר (אין קובץ 5MB שנשכח בלי אופטימיזציה).

## שלב 5 — מסירה

1. Commit עם הודעה ברורה (כמה פרויקטים/תמונות נוספו לאיזו גלריה) + push.
2. הרץ **/deploy-ifeel** (או אמור לאורן להריץ) — הוא יעלה גם את התמונות וגם את הדפים.
3. דווח לאורן: כמה נוספו, לאיזו גלריה, המונה החדש, ותזכורת שתמונות פרויקט חדשות הן
   חומר גלם מצוין לפוסט ברשתות (pipeline ב-`D:\Claude\ifeel-social\`).

## אל-תעשה

- אל תוסיף למערך `P` בלי לעדכן את רשימת הזחלנים הסטטית — ולהפך.
- אל תשנה את המבנה/עיצוב של דפי הגלריה — רק מוסיפים רשומות בתבנית הקיימת.
- אל תעלה תמונה לא מאופטמת או עם שם קובץ בעברית/רווחים.
- אל תמציא פרטי פרויקט (מיקום, היקף, מערכות) — מה שאורן לא סיפק, שאל או השמט.
- אל תשכח לעדכן מוני פרויקטים מפורסמים (callout ב-/projects/ ועוד).
